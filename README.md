# Classroom Dashboard (Updated Starter)

## Included updates
- Monthly calendar with clickable date boxes (no obvious plus button).
- Click a date to add a task, assignment, event, meeting, or holiday.
- Holiday dates display a large cross across the full calendar box.
- Existing calendar entries can be edited or removed.
- Add, edit, and delete subjects.
- Class roster includes an officer-designation column.
- Add, edit, and delete committees, with chairperson and responsibilities.
- Class constitution framework with articles on officers, meetings, resolutions, committees, accountability, academic support, elections, due process, amendments, and school-rule precedence.
- Announcements, assignments, resources, dark mode, and JSON backup/import.

## Run / publish
Open `index.html` in a browser. For GitHub Pages, upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root, then choose **Settings → Pages → Deploy from a branch → main → /(root)**.

## Data and privacy
Data is stored in the current browser only; it does not synchronize between devices. This prototype has no authentication or secure shared database. Do not enter private student information, real grades, or attendance records on a public site. The constitution is a starter framework and should be reviewed with the class adviser and school rules.
